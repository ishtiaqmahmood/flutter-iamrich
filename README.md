A simple, elegant Flutter application that demonstrates cross-platform UI development, static image asset management, and custom app bar styling in Flutter.

---

## 📖 Overview

**I Am Rich** is a classic Flutter starter project designed to showcase basic Flutter concepts:
- Building Material UI applications.
- Integrating asset management (`pubspec.yaml` assets configuration).
- Customizing app themes, background colors, and typography.
- Displaying high-resolution images smoothly across devices.

---

## ✨ Features

- **Minimalist & Modern UI**: Built using Flutter's Material Design component library.
- **Cross-Platform Support**: Runs seamlessly on iOS, Android, Web, macOS, Windows, and Linux.
- **Custom Assets**: Uses bundled local image assets stored in the repository.

## 🚀 Getting Started

### Prerequisites

To build and run this application, ensure you have the following installed on your machine:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (version 3.10.0 or higher)
- [Dart SDK](https://dart.dev/get-dart)
- An IDE such as [VS Code](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio) with Flutter and Dart extensions installed.
- An emulator or connected physical device (Android, iOS, or Desktop).

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/iamrich.git
   cd iamrich
   ```

2. **Get dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```
